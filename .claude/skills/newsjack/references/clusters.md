story's material/sector to the relevant cluster below and link naturally in-body (not a link dump).

## Rules
- Anchor text = descriptive product/topic phrase, never "click here".
- Related-news link: pick the closest prior `/news` item by material or sector.
- If no cornerstone fits, the story is probably off-beat — reconsider selection.
